# Tableau Public Build Guide

Use the lightweight CSVs in `data/` plus the generated raw dataset.

Recommended views:
1. Retailer C monthly cancellation trend.
2. September retailer comparison.
3. Daypart cancellation rate with 95% confidence intervals.
4. Store impact ranked by excess cancellations.
5. Root-cause mix.
6. Monitoring-method comparison.
7. Province quality cut.

Required note: all data is simulated, and the September Retailer C issue is intentionally injected to test detection and diagnosis.

Suggested dashboard title: **Marketplace Fulfillment Quality Diagnostic**.
